# Meridian — Health AI Governance Observatory

A single-page reference site on the regulation, ethics and governance of
artificial intelligence in health care. No frameworks, no build step, no
dependencies. Open `index.html` and it runs.

## Files

```
index.html                  Structure, metadata, JSON-LD
css/styles.css              All styling — 21 numbered sections, see the header comment
js/data.js                  All content as structured data (edit this to update the site)
js/main.js                  All behaviour — 15 numbered initialisers
build.py                    Optional: inlines everything into one portable file
meridian-single-file.html   Generated by build.py; useful for email or a static host
```

Serve the folder over HTTP rather than opening from `file://` if you want the
Google Fonts request and any future `fetch` calls to behave normally:

```bash
python3 -m http.server 8000     # then visit localhost:8000
```

## Updating the content

Everything on the page comes from `js/data.js`. You should not need to touch
markup or logic to keep it current.

| Export | Drives |
|---|---|
| `HORIZON` | The hero instrument. `axisStart`/`axisEnd` bound the axis; each milestone needs an ISO `date` |
| `JURISDICTIONS` | Map markers and region detail. `lat`/`lon` are projected, so markers cannot drift out of sync with the text |
| `ETHICS` | The six WHO principle cards. `icon` is a raw SVG path on a 24×24 grid |
| `TIMELINE` | The 2019–2028 timeline. Set `future: true` to render an entry in amber |
| `COMPARE` | Regulatory-posture cards. `dial` is 1–5 |
| `PRINCIPLES`, `RISKS`, `OPPS`, `RESOURCES`, `FAQ` | The remaining sections |

Past, next and future states are computed from the clock at render time, so the
horizon panel and its day counter stay correct after publication. Adding a new
milestone is enough; nothing needs to be re-flagged by hand.

If markers move to new jurisdictions, note that the map is a 5° dot matrix. The
land mask lives in `LAND_ROWS` in `js/main.js` as inclusive column ranges per
latitude row — coarse by design, and cheap to adjust.

## Wiring up the contact form

`js/main.js` defines `FORM_ENDPOINT = null` near the form initialiser. Set it to
your own URL and the form will `POST` JSON to it with proper pending, success and
failure states. Left as `null`, it validates the input and then hands the reader a
composed email rather than pretending to have delivered anything.

## Accessibility and performance notes

- Skip link, visible focus rings throughout, and keyboard operation for the map
  markers, accordion, mobile menu and every control.
- `prefers-reduced-motion` is honoured in both CSS and JS. Nothing that animates
  in is left hidden when motion is disabled, which is the usual way reveal
  animations break for those readers.
- Text colours were chosen against the background for WCAG AA: body text is
  roughly 17:1, secondary text 7:1, and the faint tone is reserved for small
  print at about 4.6:1.
- The canvas caps node count by viewport area and device pixel ratio at 2, and
  the loop stops entirely when the hero leaves the viewport or the tab is hidden.
- Scroll and pointer handlers are throttled to one call per animation frame.
- Reveal observers unobserve after firing, so nothing accumulates.
- Around 150 KB uncompressed in total, and the only network request beyond the
  page itself is the font stylesheet.
- A print stylesheet is included: chrome is dropped, accordions open, and link
  targets are printed.

## Content currency

Regulatory dates in this field move, and several moved during 2026. The register
reflects the position as at **3 August 2026**, including the EU Digital Omnibus on
AI adopted in June 2026, which deferred the high-risk deadlines — Annex III to
2 December 2027 and Annex I, the route most clinical AI travels, to 2 August 2028
— while leaving the Article 50 transparency duties on their original date.

Verify anything you intend to rely on against the issuing body. The Resources
section links to primary sources for exactly this reason. Nothing here is legal
advice.

## Design decisions worth knowing

- **Type.** Newsreader for display, IBM Plex Sans for body, IBM Plex Mono for
  dates and legal citations. The serif signals a journal register rather than a
  product launch; mono is used where the content genuinely is a citation
  (`Art. 50(2)`, `Annex III`), not as decoration.
- **Amber.** The brief specified blue, cyan and purple. Amber is added as a fifth
  colour reserved for regulatory status — deferred, contested, upcoming. Status is
  the subject matter of this site, so it earns a hue outside the accent family.
- **The hero.** The signature element is a live instrument rather than a large
  number over a gradient. It plots real dated obligations against today, because
  the site's actual argument is that clinical AI is governed by several clocks
  running at once.
- **Structural labels.** Section eyebrows carry content-derived labels
  (`Jurisdictions · 9`, `Timeline · 2019–2028`) instead of decorative `01/02/03`
  numbering. The timeline is numbered by date, because there the order genuinely
  carries information.
